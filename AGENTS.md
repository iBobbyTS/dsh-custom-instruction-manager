# Development rules

Maintain a DSH GUI for instruction files, skills, sources and MCP configuration, using official Host APIs and browser slots. Patching DSH source or adding a second HTTP trust fence is outside scope.

- Reuse DSH's `/api` trust boundary. Keep file writes within the selected writable source and preserve unrelated files/configuration.
- Preserve exact Session ownership in statistics: copied history is shared evidence, not another invocation. Keep secrets and message bodies out of persisted invocation identities.
- `src/` is the editable implementation; `lib/` is generated by the build. Follow [CONTRIBUTING](CONTRIBUTING.md) for setup and checks, and update both language entry points and affected [guides](docs/guide.md) when behavior changes.
- This fork's installation, support and update links belong to `iBobbyTS/dsh-custom-instruction-manager`; attribute upstream separately. Do not replace the fork with the upstream npm package.

开发、构建与交付遵循父目录 [统一规范](../docs/plugin-development.md)。`src/` 是编辑源，`lib/` 由显式构建生成并与源码一同交付。
